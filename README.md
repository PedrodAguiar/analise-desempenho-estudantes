# 📊 Análise de Desempenho de Estudantes

Projeto de análise exploratória de dados desenvolvido em Python com o objetivo de investigar a relação entre os hábitos dos estudantes e seu desempenho acadêmico.

A análise utiliza dados sobre horas de estudo, uso de redes sociais, consumo de streaming, horas de sono, frequência nas aulas, prática de exercícios físicos, saúde mental e nota final.

## 🎯 Objetivos

O projeto busca responder perguntas como:

* Existe relação entre as horas de estudo e a nota final?
* O uso de redes sociais está relacionado ao desempenho acadêmico?
* Existe uma relação entre horas de sono e desempenho?
* A frequência nas aulas influencia as notas?
* Qual variável apresenta maior correlação com a nota final?
* Quais hábitos são mais comuns entre estudantes com melhor desempenho?

## 🔎 Análises realizadas

O projeto contempla etapas de:

1. Importação e exploração inicial dos dados;
2. Verificação da estrutura e qualidade da base;
3. Análise estatística das variáveis;
4. Criação de categorias para facilitar a análise;
5. Análise da relação entre hábitos e desempenho;
6. Visualização dos dados utilizando gráficos;
7. Análise de correlação entre as variáveis;
8. Identificação dos fatores com maior relação com a nota final.
